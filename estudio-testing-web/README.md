# Estudio: Testing de Software

Sitio estático (HTML + CSS + JS), sin dependencias ni build.

## Usar
Abrí `index.html` en el navegador (o `npx serve .`).

## Estructura
- `index.html`: contenido teórico (pestañas Conceptos, Enfoques, Casos de prueba, Defectos)
- `css/styles.css`: estilos (modo claro/oscuro automático)
- `js/app.js`: pestañas, práctica A–E y quiz (arrays `cases` y `Q` para agregar preguntas)

## Publicar gratis
GitHub Pages / Netlify / Vercel: subí la carpeta tal cual.
